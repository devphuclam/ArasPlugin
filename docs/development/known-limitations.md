# Known Limitations

The following are current documented limitations, not domain invariants:

- Pull is not a complete synchronization implementation.
- Clone/document physical attachment behavior requires verified schema and environment evidence.
- Non-main branches are local/staging-oriented unless remote snapshot semantics are verified.
- Some PDM commit/file-link behavior depends on server capabilities not established in every environment.
- Some UI surfaces are placeholders or partially wired.
- OCR and CAD integration can depend on machine-specific Windows SDK, COM, and external application availability.

Consult archived source `docs/archive/legacy-ai-work-kit/docs/ai/07_KNOWN_LIMITATIONS.md` for historical detail.
