# ADR-0007: One Ticket Per Pull Request

## Status
Accepted

## Context
Large AI-generated changes are difficult to review and roll back.

## Decision
Keep one ticket per pull request and do not implement an entire epic in one change.

## Consequences
Changes remain reviewable and rollback boundaries stay small.
